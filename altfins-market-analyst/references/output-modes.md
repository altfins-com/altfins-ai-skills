# Output Modes

Use this file to choose the right output shape before writing the final analysis.

## Short outlook

Use when:

- the user asks for a quick read on one asset
- the answer should stay compact
- the evidence base is small but sufficient

Typical sections:

- Objective
- Validated Facts
- Interpretation
- Key Risk or Open Question

## Structured analysis memo

Use when:

- the user wants a complete analysis
- there are multiple evidence layers
- the answer needs explicit fact vs inference separation

Typical sections:

- Objective
- Validated Facts
- Interpretation
- Open Questions
- Suggested Next Checks

## Market scan summary

Use when:

- the task spans several assets or candidates
- the output needs comparison and prioritization
- the user wants a shortlist or overview rather than one deep dive

Typical sections:

- Scan Objective
- Top Candidates
- Common Signals or Patterns
- Risks or Missing Inputs
- Suggested Follow-Up Checks

## Follow-up investigation plan

Use when:

- the evidence is incomplete
- the target interface or runtime tool availability is not yet confirmed
- the safest answer is a next-step plan rather than a full analysis

Typical sections:

- Objective
- Available Evidence
- Missing Inputs
- Best Next Checks
