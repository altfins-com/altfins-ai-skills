# Skill Roadmap

This roadmap keeps the first iteration conservative. The aim is to mature the skills in phases without claiming unsupported altFINS behavior.

## Phase 1

### altfins-market-analyst

- Establish the initial skill contract and scope boundaries.
- Define conservative MCP-driven research guidance without naming unvalidated tool methods.
- Capture trusted source rules for market analysis workflows.

### altfins-market-researcher

- Establish the initial CLI research workflow guidance.
- Emphasize command discovery and verification against the real installed CLI.
- Keep output expectations structured and export-friendly.

### altfins-query-builder

- Establish the translation workflow from plain-English intent to structured research prompts.
- Emphasize clarification and decomposition over direct execution.
- Capture safe boundaries for future CLI or MCP handoff shapes.

## Phase 2

### altfins-market-analyst

- Add validated reference material for recurring MCP-based research patterns.
- Add reusable analysis templates only after real MCP workflows are confirmed.
- Introduce stricter output patterns for evidence-backed summaries.

### altfins-market-researcher

- Add validated CLI command patterns once the supported command surface is confirmed.
- Add reusable export or handoff templates for repeatable research tasks.
- Add narrowly scoped helper scripts if repeated formatting or validation becomes necessary.

### altfins-query-builder

- Add reusable translation templates for common trader intents.
- Add more structured mappings from intent to research brief format.
- Add safer handoff conventions for future CLI or MCP execution layers.

## Phase 3

### altfins-market-analyst

- Refine analysis workflows around real-world MCP usage feedback.
- Add packaging and validation support once the skill contract is stable.
- Consider selective implicit invocation only if the skill proves consistently safe and useful.

### altfins-market-researcher

- Refine packaging readiness for standalone distribution.
- Add validation for stable CLI-oriented examples and output shapes.
- Revisit whether any shared tooling is justified by real reuse.

### altfins-query-builder

- Expand prompt-to-structure coverage based on real usage.
- Add validation for common translation scenarios and failure modes.
- Reassess implicit invocation only after the skill shows predictable behavior.
